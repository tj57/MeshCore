# mcRPC in MeshCore

The normative library and protocol docs are in the **standalone mcRPC repository**
(this tree: `lib/mcrpc` → symlink/submodule).

| Doc | Location |
|-----|----------|
| Protocol | `lib/mcrpc/docs/protocol/SPEC.md` |
| API | `lib/mcrpc/docs/api/API.md` |
| Transport guide | `lib/mcrpc/docs/architecture/TRANSPORT.md` |
| Migration | `lib/mcrpc/docs/development/MIGRATION_MESHCORE.md` |

MeshCore-specific notes in this `doc/` folder (`PRIVATE_CHANNELS.md`, `BOARDS.md`, …)
describe deployment on MeshCore radios only.

`doc/mcRPC-CORE.md` is retained as a historical/local copy; prefer the standalone SPEC.
